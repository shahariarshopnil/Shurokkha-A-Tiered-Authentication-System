Each linked app gets its own ECDSA P-256 keypair per device, private key generated non-extractable. Every approval is a real signature, verified against the public key the app's server stored at link time. Offline approvals use HMAC-SHA1 over the challenge with RFC 4226 truncation to 8 digits.
